# portfolio

Personal portfolio site of Nathanael Cammay, Software Developer.

Built with [Astro](https://astro.build) and React, and deployed to GitHub Pages with GitHub Actions.

Live at https://nathanaelcammay.com

## Running locally

Requires Node 22.12 or later.

```sh
npm install
npm run dev      # dev server at http://localhost:4321/
npm run build    # production build into dist/
npm run preview  # serve the production build
npm run images   # regenerate favicon.ico, apple-touch-icon.png and og-image.png
```

[docs/hosting.md](docs/hosting.md) explains how the site is built and deployed.
